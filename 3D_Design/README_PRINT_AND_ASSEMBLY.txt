========================================================================
4-Axis Helmet-Mounted Drone Tracking Gimbal (V2) - Print & Assembly Guide
دليل الطباعة والتعديل والتجميع - مثبت كاميرا 4 محاور للخوذة العسكرية
========================================================================

1. محتويات الحزمة:
------------------
- stl/
    * 01_helmet_base.stl           (86 x 66 x 67 mm)   - قاعدة الخوذة وحامل سيرفو Roll
    * 02_roll_u_frame.stl          (63 x 78 x 65.5 mm) - إطار Roll وحامل سيرفو Pitch الأفقي
    * 03_pitch_platform_imu.stl    (60 x 54 x 26 mm)   - المنصة الأفقية 0° (مقلوبة للطباعة بدون دعامات)
    * 04_yaw_hub_mg90s.stl         (22 x 47.6 x 47 mm) - محور 360° المرتفع وحامل MG90S
    * 05_camera_bracket.stl        (34 x 34.5 x 29.5)  - حامل الكاميرا على MG90S (لوح سفلي + خلفي)
    * 00_full_assembly_preview.stl                     - تجميع كامل للمعاينة فقط
- openscad/
    * params.scad                  - ملف المتغيرات الرئيسي (عدّل ثقوب الخوذة والكاميرا من هنا!)
    * helmet_gimbal_4axis.scad     - النموذج البارامتري الكامل (يفتح في OpenSCAD أو FreeCAD)
    * export_01..05_*.scad         - ملفات تصدير فردية بضغطة زر
- gimbal_blueprint_preview.png     - مخطط ثلاثي الأبعاد للأجزاء والتجميع

2. التعديل على أرض الواقع (في أقل من دقيقة):
--------------------------------------------
افتح openscad/params.scad وعدّل فقط:
  * ثقوب الخوذة: helmet_hole_dx, helmet_hole_dy, helmet_screw_d
  * ثقوب الكاميرا: cam_hole_dx, cam_hole_dy, cam_back_dy, cam_back_dz, cam_screw_d
  * سماحية الطابعة: tol (الافتراضي 0.4 مم)
ثم افتح أي ملف export_0X_*.scad في OpenSCAD واضغط F6 ثم File -> Export as STL.

3. إعدادات الطباعة الموصى بها (Cura / PrusaSlicer / OrcaSlicer):
----------------------------------------------------------------
- المادة: PETG (الأفضل للتحمل الخارجي) أو PLA+
- ارتفاع الطبقة: 0.20 mm | الجدران: 3-4 جدران | الحشو: 25%-30% (Gyroid)
- القطع موجهة مسبقاً للطباعة بأقل دعامات ممكنة (فعل Tree Supports - Touching Buildplate فقط عند الحاجة).

4. البراغي والمحركات المطلوبة:
------------------------------
- 2x MG996R (180°) + أقراص التثبيت 25T
- 1x 28BYJ-48 (5V) + درايفر ULN2003
- 1x MG90S + ذراع التثبيت
- 1x MPU6050 (GY-521)
- 2x برغي M4x16mm + صواميل قفل + رونديلات نايلون (للمحاور الحرة المقابلة لـ MG996R)
- 8x M3x12mm (لـ MG996R)، 2x M4x10mm (لـ 28BYJ-48)، 2x M3x8mm (لـ MPU6050)، 2x M2x8mm (لـ MG90S)
- 4x M4 لتثبيت القاعدة على الخوذة + براغي M3/M2 للكاميرا
